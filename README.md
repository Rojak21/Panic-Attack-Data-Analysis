🧠 Panic Attack Data Analysis | Snowflake + Power BI

A Panic Attack Data Analysis Dashboard built using Snowflake, SQL, and Power BI to analyze patient symptoms, panic attack patterns, and demographic insights.

🔧 Tools & Technologies

Snowflake | SQL | Power BI | DAX | Power Query

📊 Project Highlights
Used Snowflake as the primary data source for storing and querying the panic attack dataset.
Wrote SQL queries in Snowflake to retrieve and prepare data for analysis.
Built an interactive 3-page Power BI dashboard covering:
Patient symptoms and symptom counts
Panic attack patterns and patient characteristics
Age-group analysis using sleep hours, panic scores, and attack frequency
Created DAX measures for analytical calculations.
Added slicers and interactive visualizations to enable data exploration.
